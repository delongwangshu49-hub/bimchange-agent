# BIMChange-Agent v0.9.0

## Stable bounded R3 release / 有界完整 R3 稳定版

BIMChange-Agent v0.9.0 promotes the complete research-gated R3 slice into the default offline Windows review workflow. The deterministic report remains authoritative; AI remains disabled by default and optional.

BIMChange-Agent v0.9.0 将经过研究闸门验证的完整 R3 子集纳入默认 Windows 离线审阅流程。确定性报告仍是权威事实来源；AI 继续默认关闭且完全可选。

### Included / 本次包含

- Existing IFC4 addition, deletion, and property-value modification records.
- Verified placement-only translation with independent reconstruction.
- Independent metre-normalized `XDim`, `YDim`, and extrusion `Depth` changes for one Body `IfcExtrudedAreaSolid` using one `IfcRectangleProfileDef`.
- Topology-preserving vertex changes for one Body `IfcTriangulatedFaceSet`.
- Direct spatial containment, aggregation/decomposition, type-assignment, and material-association changes.
- Stable product artifact Schema `0.4.0`, stable `diff-r3`, `query-r3`, and `report-r3` commands, bilingual HTML, desktop review, and JSON/HTML export.

- 保留既有 IFC4 新增、删除与属性值修改记录。
- 通过独立重建验证的纯放置平移。
- 对单一 Body `IfcExtrudedAreaSolid` + 单一 `IfcRectangleProfileDef`，分别重建并统一为米的 `XDim`、`YDim` 与拉伸 `Depth` 变化。
- 对单一 Body `IfcTriangulatedFaceSet` 的拓扑不变顶点变化。
- 直接空间包含、聚合/分解、类型指派与材料关联变化。
- 稳定产品产物 Schema `0.4.0`、稳定 `diff-r3`、`query-r3`、`report-r3` 命令、双语 HTML、桌面审阅及 JSON/HTML 导出。

### Release evidence / 发布证据

The deterministic synthetic acceptance pair produces 10 supported records in one comparison: 1 addition, 1 deletion, 1 property modification, 3 geometry modifications, 4 relationship modifications, and 0 unsupported records. The stable release gate reached two clean builds with identical normalized semantics, 100% unique trace resolution, 16/16 fixed tamper cases rejected, zero false acceptance, zero privacy violations, and zero model/API calls. Product/desktop/reporting and complete-R3 research suites passed for the stable build; final package hashes and smoke results are recorded in the local release audit before upload.

确定性合成验收对在一次比较中产生 10 条受支持记录：新增 1、删除 1、属性修改 1、几何修改 3、关系修改 4、未支持 0。稳定版发布闸门达到两次干净构建规范化语义一致、证据唯一解析率 100%、固定 16 项篡改全部拒绝、误接受 0、隐私违规 0、模型/API 调用 0。稳定构建的产品/桌面/报告与完整 R3 研究套件均已通过；最终包哈希和烟雾测试结果已记录在上传前的本地发布审计中。

### Boundaries / 边界

This release supports exact IFC4 only, no more than 50 MiB and 5,000 `IfcElement` objects per revision, with at least 50% shared element GlobalIds on the smaller side. Rotation, other profile or solid kinds, extrusion-direction changes, openings/projections, tessellated topology changes, nested material usage, mixed semantics, ambiguous reconstruction, IFC2X3, and arbitrary real-project compatibility remain unsupported or indeterminate. The unsigned Windows artifacts may trigger SmartScreen. These results are not professional engineering validation.

本版本仅支持精确 IFC4；单文件不超过 50 MiB、每版不超过 5,000 个 `IfcElement`，且较小一侧至少 50% 的构件 GlobalId 重合。旋转、其他轮廓或实体类型、拉伸方向变化、洞口/投影、网格拓扑变化、嵌套材料用法、混合语义、重建歧义、IFC2X3 与任意真实项目兼容性仍为未支持或无法判定。Windows 产物未签名，可能触发 SmartScreen。本结果不构成专业工程验证。
