# BIMChange-Agent v0.5.0 — brand and product-experience iteration

## Release position / 发布定位

v0.5.0 turns the earlier Windows engineering preview into a more coherent installable desktop experience. It keeps the same deliberately bounded IFC4 product contract: deterministic Change Records remain authoritative, while AI stays optional and off by default.

v0.5.0 在既有 Windows 工程预览基础上形成更完整的可安装桌面体验。产品仍保持主动收窄的 IFC4 边界：确定性 Change Records 始终是事实源，AI 默认关闭且只作为可选解释层。

## What changed / 主要变化

- professional bilingual desktop design with light, dark, and system appearance modes;
- responsive report layout, per-pixel scrolling, smoother splitter interaction, filtering, evidence detail, and JSON/HTML export;
- a clear animated AI switch plus classified provider errors that preserve the deterministic report;
- explicit offline adapters for DeepSeek, OpenAI, Anthropic, and Google Gemini, without silent fallback;
- a unified settings centre for language, appearance, provider, model, and in-memory API key entry;
- original product branding across the app, taskbar, Start Menu, desktop shortcut, executable, and installer;
- a current-user Windows installer with verified install, launch, and uninstall behavior.

## Install / 安装

1. Download `BIMChange-Agent-0.5.0-win-x64-setup.exe` and `BIMChange-Agent-0.5.0-win-x64-setup.exe.sha256.txt` from the GitHub Release.
2. Run `Get-FileHash .\BIMChange-Agent-0.5.0-win-x64-setup.exe -Algorithm SHA256` in PowerShell and compare the result with the sidecar.
3. Run the installer. It targets the current Windows user by default and creates Start Menu and desktop shortcuts.
4. Launch BIMChange-Agent, keep AI off for the first local comparison, and select the old and revised IFC4 files.

1. 从 GitHub Release 下载安装包及同名 SHA-256 校验文件。
2. 在 PowerShell 中运行上述 `Get-FileHash` 命令并核对结果。
3. 运行安装程序；默认安装到当前 Windows 用户，并创建开始菜单与桌面快捷方式。
4. 启动 BIMChange-Agent，首次比较建议保持 AI 关闭，再选择旧版与新版 IFC4。

## Boundaries / 边界

- Windows 10/11 x64; exact IFC4 only;
- no more than 50 MiB and 5,000 `IfcElement` objects per file;
- at least 50% shared element GlobalIds on the smaller version;
- normalized additions, deletions, and property-value modifications;
- no claim of arbitrary IFC compatibility, geometry-diff coverage, professional safety review, or regulation checking;
- IFC2X3 remains a separate research track and is not enabled in this product version;
- live provider availability and output quality are not certified by the offline adapter tests;
- the installer is not code-signed and Windows may show an unknown-publisher warning.

## Privacy / 隐私

The deterministic IFC comparison stays local. When AI is explicitly enabled, the provider payload is limited to at most 200 normalized records and excludes IFC files, absolute paths, file names, and the API key. Normalized records may still contain project-derived names, storeys, and property values, so users must confirm that external processing is permitted before enabling AI.

确定性 IFC 比较始终在本机完成。只有用户明确开启 AI 时，程序才会发送最多 200 条规范化记录；载荷不包含 IFC 文件、绝对路径、文件名或 API Key。规范化记录仍可能包含项目派生的名称、楼层和属性值，因此开启 AI 前必须确认项目允许外部处理。

## Upgrade note / 升级提示

The installer removes and recreates the same-named desktop and Start Menu shortcuts so they reference the versioned `BIMChange-Agent-0.5.0.ico`. If Windows briefly displays a cached old icon after an in-place upgrade, refresh the desktop or sign out and back in.

安装器会删除并重建同名桌面与开始菜单快捷方式，使其显式引用版本化 `BIMChange-Agent-0.5.0.ico`。若覆盖安装后 Windows 短暂显示旧图标缓存，可刷新桌面或重新登录。
