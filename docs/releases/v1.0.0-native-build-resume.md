# Native build recovery / 原生构建续跑

The 2026-09-12 run `34691147135` failed in the SWIG-generated Python
wrapper with three MSVC C2248 errors. OCCT (33m59s) and Boost (51s) succeeded.
Their installed outputs and CMake evidence are retained in the authenticated
`native-ifc-built-dependencies` artifact, and OCCT also has an Actions cache.
The IFC intermediate objects from that run were **not** retained: they cannot
be recovered by clicking GitHub's “Re-run failed jobs”.

该次失败出现在 Python 接口，不是产品模型处理。已保存的 OCCT/Boost 可以直接
复用，但当时未归档 IFC 中间对象，因此本次仍需重新编译 IFC 核心。

## Recovery changes / 续跑改进

- `reuse_dependencies=true` downloads the successful dependency artifact from
  run `34691147135`; verifies its exact runner image and recorded CMake evidence;
  skips both compilation steps. Missing/mismatched outputs stop the build;
  there is no silent full-rebuild fallback.
- A minimal, hash-guarded patch moves two kernel-independent OpaqueCoordinate
  SWIG template declarations outside the upstream CGAL conditional. Base commit
  remains `1c5b825d8ef05ab9d14a15dac12e9eae2f5a37c2`; this is explicitly a
  **patched build**, not an unmodified upstream binary. No native geometry
  algorithm, schema set or project license changes. Original LGPL notices remain.
  The complete patch and digest receipt accompany the wheel/build evidence.
- The wrapper's actual MSVC compile runs before the lengthy core build; linking
  and the full ordinary CMake dependency build are still required afterwards.
- `native-ifc-checkpoint` saves IFC build outputs, including objects and static
  libraries, even after failure. `checkpoint_run_id` restores a compatible
  checkpoint only when runner image, Python, absolute paths, source pins and
  build recipe match. Unchanged input timestamps are restored only after content
  digest checks; changed inputs stay fresh and normal MSBuild dependency checks
  decide what needs rebuilding. Archive paths/CRCs and overwrite refusal are
  checked. This preserves reusable work, not permission to skip verification.

默认复用已成功依赖；不匹配就停止，避免用户不知情地再次全量编译。新流程先编译
接口，再编译核心。之后即使失败也保存 IFC 中间产物；后续提供兼容运行 ID 可续跑，
只恢复内容未变文件的旧时间戳，变化文件仍由正常构建系统重新检查。

## Evidence and limits / 证据及限制

With SWIG 4.4.1, local generation from the exact upstream interface reproduced
three `SwigValueWrapper<IfcGeom::OpaqueCoordinate<...>>` declarations. Applying
the patch produces direct OpaqueCoordinate result variables for all three.
That generation test is not a substitute for CI C++ compilation or native
geometry/installer acceptance. Offline suite: 74 passed, 3 native opt-in skipped.
