# BIMChange-Agent v0.8.0-rc.1

Release candidate: 2026-08-23

Platform: Windows 10/11 x64

Positioning: bounded IFC4 placement-translation candidate

候选日期：2026-08-23

平台：Windows 10/11 x64

定位：边界明确的 IFC4 放置平移候选版本

## What changed / 本次更新

v0.8.0-rc.1 moves one research-gated geometry semantic into the default desktop review path: placement-only translation. A geometry change is supported only when the same IFC4 element preserves its GlobalId and type, its local canonical shape and rotation remain unchanged, object placement and shape transformation independently reconstruct the same project-world displacement, and the displacement meets the product threshold.

v0.8.0-rc.1 将一种经过研究闸门验证的几何语义整合进默认桌面审阅路径：纯放置平移。只有同一 IFC4 构件保持 GlobalId 与类型不变、局部规范形状与旋转不变、对象放置和形状变换独立重建出相同的项目世界坐标位移，并且位移达到产品阈值时，几何变化才会被支持。

The desktop summary, filters, detail pane, unified JSON/HTML reports, and optional AI explanation input can now represent `geometry_modified / placement_translation`. Details include the old and new origins, X/Y/Z displacement, distance in metres, and the deterministic evidence selector. Existing addition, deletion, and property-value semantics remain available.

桌面汇总、筛选、详情面板、统一 JSON/HTML 报告及可选 AI 解读输入现在可以表达 `geometry_modified / placement_translation`。详情包含新旧原点、X/Y/Z 位移、米制距离和确定性证据位置；既有新增、删除和属性值修改语义继续保留。

## Fail-closed boundary / 失败关闭边界

Rotation, general dimension or shape changes, deformation, unresolved geometry, local-shape changes, and below-threshold movement are not classified as supported translation. When the evidence channels disagree or reconstruction fails, the application keeps the result unsupported instead of guessing. Absence of a geometry record is not proof that geometry is unchanged.

旋转、一般尺寸或形状变化、变形、无法重建的几何、局部形状变化及低于阈值的位移不会被归类为受支持平移。当证据通道不一致或重建失败时，应用会保持未支持状态，而不是猜测。没有几何记录也不等于几何未变化。

## Product boundary / 产品边界

- exact IFC4 only;
- no more than 50 MiB per file;
- no more than 5,000 `IfcElement` objects per revision;
- at least 50% shared element GlobalIds on the smaller side;
- supported normalized changes: addition, deletion, property-value modification, and verified placement-only translation;
- IFC2X3, general geometry diff, 3D preview, Revit integration, automatic update, and professional engineering validation remain outside this candidate.

- 仅支持精确 IFC4；
- 单文件不超过 50 MiB；
- 每版最多 5,000 个 `IfcElement`；
- 较小一侧至少 50% 的构件 GlobalId 重合；
- 受支持的规范化变化为新增、删除、属性值修改及经验证的纯放置平移；
- IFC2X3、通用几何差分、三维预览、Revit 集成、自动更新与专业工程验证仍不在本候选范围内。

## AI and privacy / AI 与隐私

AI remains off by default. The deterministic comparison stays local. When AI is explicitly enabled, the bounded payload excludes IFC binaries, absolute local paths, file names, and API keys, but normalized records may still contain project-derived identifiers, storeys, fields, values, evidence selectors, and geometry origins/displacement vectors. Enable it only when the project permits external processing. AI output may contain errors and never replaces deterministic evidence or professional review.

AI 继续默认关闭，确定性比较在本机完成。明确启用 AI 时，受限载荷不包含 IFC 二进制文件、绝对本地路径、文件名或 API Key，但规范化记录仍可能包含项目派生的标识符、楼层、字段、值、证据位置及几何原点/位移向量；只有项目允许外部处理时才应启用。AI 输出可能存在错误，不能替代确定性证据或专业审阅。
