状态：尚未达到公开二进制分发条件。2026-09-12，作者授权上传已审核源码、文档与公开合成图片。本次源码更新不包含验证二进制、稳定 Release/标签创建或在用安装修改。

## Verification / 验证

Local results are recorded in the [1.0.0 preparation audit](v1.0.0-local-audit.md): 73 unique tests passed, plus quickstart and frozen synthetic 3D smoke. Local validation ZIP and installer were built; the installer was not installed. These are not final public assets.

本地结果见 [1.0.0 准备审计](v1.0.0-local-audit.md)：73 项不重复测试通过，另通过 quickstart 与冻结合成三维烟雾。已构建本地验证 ZIP 和安装器，未执行安装；它们不是最终公开附件。

Run `python scripts/verify_release.py` for source/docs/assets and `--public` to check public gates. Passing the local check does not mean binary distribution is ready. Full unit, R3/R4, native WebEngine and frozen package results must be recorded separately; prior candidate evidence is not a substitute for 1.0.0 binary acceptance.

本地检查验证源码/文档/资源；`--public` 检查公开条件。本地 PASS 不代表二进制可公开。完整单测、R3/R4、原生 WebEngine 和冻结包结果须分别记录，旧候选版证据不可替代 1.0.0 二进制验收。

## Remaining release gates / 尚未闭环的发布条件

- [ ] Exact FINAL binary inventory and module-by-module license review, including any unused QML/Quick3D modules collected by PyInstaller. / 最终二进制清单与逐模块许可证复核，包含误收集的未使用 QML/Quick3D。
- [ ] Exact Qt 6.11.1 / Chromium and other native dependency notices plus corresponding-source materials and replacement/build instructions. Wheel metadata and upstream homepages alone are insufficient evidence of completion. / 精确版本声明、对应源码材料及替换/构建说明；wheel 元数据与上游首页不能证明已闭环。
- [ ] Rebuild final distributable, verify hashes/version/resources and frozen offline 3D operation against that exact package. / 重建最终分发包，核对哈希/版本/资源，对该包验证冻结离线三维。
- [ ] Authorized isolated install/launch/uninstall and upgrade validation using the stable AppId, without touching the user's installed copy. / 获授权后隔离验证安装/启动/卸载与稳定 AppId 升级，不触碰用户在用安装。
- [ ] Maintainer authorization for exact reviewed paths and assets; remove preparation wording only after publication status is true. / 作者授权精确审阅路径与附件；只有发布状态属实时才删除准备中说明。

Qt's [WebEngine licensing](https://doc.qt.io/qt-6.11/qtwebengine-licensing.html) describes separate Qt/Chromium obligations. [Qt Quick 3D](https://doc.qt.io/qt-6.11/qtquick3d-index.html) is documented as GPLv3/commercial, so it cannot be included under a blanket LGPL notice. These rolling documentation pages currently identify 6.11.2 and are guidance, not an exact 6.11.1 binary inventory. No commercial license, project relicensing or source-supply promise is assumed.

官方页面分别说明 Qt/Chromium 义务及 Quick3D 的 GPLv3/商业许可；不能笼统按 LGPL 声明。滚动文档当前标识 6.11.2，只能作方向依据，不能代替精确 6.11.1 二进制清单。不假定已购买商业许可、不修改项目许可、不虚构源码供应承诺。

## Upload boundaries / 上传边界

Review an explicit changed-file allowlist. Preserve frozen research artifacts without rerunning or modifying them. Exclude private building-derived IFC/GLB/screenshots, outputs, temporary build roots, local governance documents, credentials and private-candidate packages. Never use `git add -A` on this dirty worktree. SHA-256 sidecars must come from the final artifacts, not an older build.

逐项审核明确变更白名单；冻结研究保留但不重跑、不修改。排除私人建筑派生 IFC/GLB/截图、outputs、临时构建、本地总纲记录、凭据及私有候选包。不得在当前脏工作树使用 `git add -A`。校验文件必须来自最终产物，不能沿用旧包。
