# BIMChange-Agent v0.1.0 — Gate 4 Evaluation Release

BIMChange-Agent v0.1.0 is the first formal research release. It freezes the completed Gate 4 controlled held-out evaluation and adds a clear, tested path for new users to inspect IFC files, query normalized Change Records, and verify the published evaluation offline.

**Product status:** source-run research prototype and developer toolkit. This is not yet a pip-installable end-user BIM application or a production-ready arbitrary IFC revision service.

## Evaluation snapshot

- Evaluation payload merged through [PR #11](https://github.com/delongwangshu49-hub/bimchange-agent/pull/11).
- Gate 4 payload merge commit: [`2562ed89f47bc6fce06613b306dffd1ec429c6df`](https://github.com/delongwangshu49-hub/bimchange-agent/commit/2562ed89f47bc6fce06613b306dffd1ec429c6df).
- Dataset: `gate4-controlled-heldout-v0.1.0`.
- 40 held-out questions × 3 workflows × 3 repetitions = 360 scheduled primary executions.
- 348 retained candidates and 12 recorded, non-retried `schema_or_output_format` experimental failures.
- Final bilingual report: [Gate 4 Controlled Held-Out Evaluation Results](https://github.com/delongwangshu49-hub/bimchange-agent/blob/main/docs/gate4-held-out-results.md).

## Core results

Across 120 scheduled executions per workflow:

| Workflow | Completion | Semantic exact match | Change F1 | Deterministic evidence support |
|---|---:|---:|---:|---:|
| Direct LLM | 97.50% | 54.17% | 63.16% | 65.83% |
| Tool-Using Agent | 94.17% | 84.17% | 91.85% | 100.00% |
| Proposed | 98.33% | 96.67% | 97.90% | 100.00% |

The blinded single-reviewer audit covered 135 sampled executions and 505 atomic claims: 501 were supported, 1 unsupported, and 3 indeterminate. Of 131 audited candidates, 90 passed citation verification and 41 did not. Conservative authoritative evaluation spend was CNY 4.67232, below the frozen CNY 25.00 ceiling.

## What users can run

Validated environment: 64-bit Python 3.13 on Windows. From a repository checkout:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\check_ifc.py
.\.venv\Scripts\python.exe scripts\query_change_records.py examples\query-added-beams.json
.\.venv\Scripts\python.exe scripts\test_quickstart.py
```

The first command inspects an IFC file and returns a deterministic JSON summary. The second accepts a JSON filter request and returns matching, schema-validated Change Records with source hashes and evidence selectors. See the [bilingual Quickstart and usage guide](https://github.com/delongwangshu49-hub/bimchange-agent/blob/main/docs/quickstart.md) for custom inputs and expected outputs.

## Recorded limitations

- Results describe one independently constructed controlled synthetic IFC4 fixture, not a universal BIM benchmark.
- Only three repetitions and one model provider were evaluated.
- The manual audit used one reviewer, so inter-rater agreement is unavailable.
- Free-text completeness was not deterministically scored beyond the structured metrics and audit.
- Per-execution latency was not persisted and cannot be reconstructed.
- Four legacy failure rows lack cumulative token/cost metadata; seven executions remain in combined attribution pools.
- Supported change types are frozen and limited; broader geometry and domain behavior are not established.
- The repository does not yet provide a supported general `old.ifc + new.ifc → normalized Change Records` command, packaging, GUI, authoring-tool integration, or engineering/compliance assurance.

The historical machine-readable private-review package retains the pre-publication readiness value that existed when it was frozen. The final report, PR #11, main-branch merge, and this release record the subsequent publication decision without rewriting frozen evaluation history.
