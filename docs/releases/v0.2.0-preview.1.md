# v0.2.0 Preview 1 — early Windows engineering preview

> This pre-release is an engineering checkpoint for feedback. It does not represent the final product experience and does not claim support for arbitrary IFC files.
>
> 本预发布版用于工程验证和收集反馈，不代表最终产品效果，也不宣称支持任意 IFC 文件。

## What is included / 包含内容

- Windows 10/11 x64 portable ZIP; extract and run without installing Python.
- Home page with old/revised IFC selection and drag-and-drop.
- Background deterministic comparison followed by a separate report page.
- Normalized JSON and self-contained HTML export.
- Optional DeepSeek explanation, disabled by default; other providers remain disabled placeholders.
- Installable Python package with `bimchange inspect`, `bimchange diff`, and `bimchange query`.

## Supported preview envelope / 预览支持边界

- Exact `IFC4` only.
- Maximum 50 MiB and 5,000 `IfcElement` objects per file.
- At least 50% shared element GlobalIds on the smaller model side.
- Added, deleted, and property-value-modified records only.
- Inputs with missing, malformed, or duplicate `IfcRoot.GlobalId` values are rejected.
- Other structured detector results are retained under `unsupported_changes`.

## Tutorial / 使用教程

1. Download the ZIP and `.sha256.txt` from this GitHub pre-release.
2. Compute `Get-FileHash .\BIMChange-Agent-0.2.0-preview.1-win-x64.zip -Algorithm SHA256` and compare it with the sidecar.
3. Extract the complete ZIP to a normal folder.
4. Double-click `BIMChange-Agent.exe`. Windows SmartScreen may show an unknown publisher because this preview is not code-signed.
5. Select or drag the old IFC into the left card and the revised IFC into the right card.
6. Leave AI off for a fully local run; click **开始分析**.
7. After the report page opens, inspect counts and rows, then export JSON or HTML if needed.

AI settings are optional. If DeepSeek is enabled, the API Key stays in process memory and the IFC files/file names are not sent, but up to 200 normalized records may contain project-derived names and values. Read the [privacy boundary](../privacy-and-security.md) first.

## Failure behavior / 失败行为

Boundary violations and analysis failures show a modal error dialog. The selection page is restored after the worker thread stops. Export failures also show a dialog. DeepSeek failures show a warning but do not discard the completed local report.

- Offline product, report, and desktop tests, including a real background-thread error path.
- Existing v0.1.0 Quickstart, query, and Gate 4 foundation regression.
- Frozen `onedir` EXE startup smoke test.
- ZIP structure, checksum, credential/path scan, dependency vulnerability scan, and third-party-license packaging audit.

## Known limitations / 已知限制

- Early engineering UI; no final visual design claim.
- No code signing or installer.
- No 3D model view, overlay, or report-row highlighting.
- No updater, telemetry, Revit integration, or multi-provider AI.
- Compatibility has been tested on controlled representative IFC4 fixtures, not a broad real-project matrix.
- Analysis cannot be cancelled while the background worker or optional provider request is active.
