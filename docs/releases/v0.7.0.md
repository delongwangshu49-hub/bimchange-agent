# BIMChange-Agent v0.7.0

发布日期：2026-08-13  
平台：Windows 10/11 x64  
定位：边界明确的 IFC4 版本审阅产品更新

## 本次更新

v0.7.0 继续优化从文件选择到报告审阅的完整路径：报告分隔条现在会保持可用边界，默认窗口与控件间距更紧凑，下拉筛选在深浅色主题中均具备清晰箭头，字体和交互状态也保持更一致的视觉层级。

可选 AI 解读会把结构化结果转换为自然语言摘要，并提供简短理性分析、关键变化、局限性与持续免责声明。中文界面请求中文输出，英文界面请求英文输出。DeepSeek 适配器补充了更明确的 JSON 请求约束与兼容解析；若服务商请求或响应失败，已经完成的本地确定性报告仍会保留。

## 产品边界

- 仅支持精确 IFC4；
- 单文件不超过 50 MiB；
- 每版最多 5,000 个 `IfcElement`；
- 较小一侧至少 50% 的构件 GlobalId 重合；
- 当前规范化新增、删除与属性值修改；
- IFC2X3、任意真实项目文件对、三维预览和 Revit 集成不在本版本支持声明内。

## AI 与隐私

AI 默认关闭，本地比较与确定性报告不需要服务商。明确启用后，应用只发送至多 200 条规范化 Change Records 及汇总数量，不发送 IFC 二进制文件、绝对本地路径、文件名或 API Key 本身。规范化记录仍可能包含实体标识、楼层名称、属性名称和修改前后值，使用前应确认项目数据允许发送至所选服务商。

API Key 只保留在当前进程内存中，不写入偏好设置或导出报告。AI 输出可能存在遗漏或错误，不构成工程、合规、安全或法律结论；所有判断均应回到原始 IFC、规范化记录与人工审阅。
