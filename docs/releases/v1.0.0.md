# BIMChange-Agent 1.0.0 / 正式版

**Windows x64 stable release / Windows x64 正式版**

Download the installer or portable ZIP from this release's Assets. No Python installation is required. The application and installer are unsigned. / 从本页 Assets 下载安装器或便携 ZIP，无需安装 Python。应用及安装器未签名。

Version 1.0.0 combines bounded deterministic IFC4 revision comparison with local 3D evidence review. The `0.4.0` record schema and R3 classification boundaries remain unchanged.

1.0.0 将有界确定性 IFC4 版本比较与局部三维证据审阅整合为正式产品。`0.4.0` 记录 Schema 与 R3 分类边界保持不变。

## Highlights / 更新重点

- Color actual IFC meshes, with contours, rather than rectangular proxy markers. / 直接对 IFC 构件网格着色并显示轮廓，不使用矩形代理标记。
- Pure black scene and subtle XY reference grid; focus, fit-context and context fading. / 纯黑场景、低对比 XY 参考网格、构件定位、查看周围与周围淡化。
- Background geometry worker, reusable session/model caches, latest-selection handling and on-demand rendering. / 后台几何进程、可复用会话/模型缓存、最新选择优先与按需渲染。
- Bilingual interface and documentation; optional four-provider AI; JSON and standalone HTML exports. / 双语界面与文档、可选四服务商 AI、JSON 与独立 HTML 导出。
- Preserved animated logo, historical product gallery and frozen research lineage. / 保留 Logo 动图、历史产品图集和冻结研究沿革。
- Related project: [IFC ClashTrace](https://github.com/delongwangshu49-hub/ifc-clashtrace), by the same author, for cross-model clash/clearance evidence. / 同作者相关项目，用于跨模型碰撞/净距证据。

## Boundaries / 边界

Exact IFC4; ≤ 50 MiB per file; ≤ 5,000 elements per revision; ≥ 50% shared GlobalIds on the smaller side. The local view contains one target and at most two unchanged same-direct-storey neighbors within 6 m. Rendering does not imply support for arbitrary geometry edits. The grid is a visual reference, not an actual building datum.

精确 IFC4；单文件 ≤ 50 MiB；每版 ≤ 5,000 构件；较小一侧 GlobalId 重合率 ≥ 50%。局部视图包含一个目标及同一直接楼层、6 米内最多两个未变化邻居。能够显示不等于支持任意几何修改。网格仅为视觉参考，不是实际建筑基准。

AI is off by default. Enabling AI sends bounded normalized records to the chosen provider and uses the API key for authentication. IFC/GLB files are not uploaded. No new live-provider, arbitrary-exporter or cross-machine validity is claimed.

AI 默认关闭；开启后向所选服务商发送受限规范化记录并使用 API Key 认证，不上传 IFC/GLB。不新增在线服务商、任意导出器或跨机器有效性声明。
