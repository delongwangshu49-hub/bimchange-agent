# Security policy

## Supported versions

v0.2.0 Preview 1 is an early engineering preview. Security fixes are handled on the latest preview branch; v0.1.0 remains a frozen research release and does not contain the desktop package.

## Reporting a vulnerability

Do not open a public issue for a vulnerability, API Key exposure, confidential IFC disclosure, or other personal/project data incident. Use GitHub's **Security → Report a vulnerability** private advisory flow for this repository.

Include the affected version, Windows version, impact, reproduction steps, and the minimum non-sensitive evidence needed to understand the issue. Do not send real credentials or confidential models. Revoke any exposed provider key before reporting it.

General non-sensitive defects and feature suggestions may use the public issue templates.
