# Research implementations

For the current 1.0.0 local release-preparation status, see the [release checklist](../docs/releases/v1.0.0-release-checklist.md). Historical research versions and measurements below retain their original meaning.

当前 1.0.0 本地发布准备状态见[发布清单](../docs/releases/v1.0.0-release-checklist.md)。以下历史研究版本与度量保留原始含义。

This directory contains isolated, offline research implementations that build on deterministic BIMChange-Agent artifacts without changing frozen release contracts.

- `r1_traceability/` generates and verifies fail-closed evidence manifests for supported Change Records and contains the controlled tamper acceptance harness.
- `r2_external_validity/` performs path-free inventory of authorised local sample roles and evaluates an IFC4 A/B/C replication against its change ledger and R1 acceptance evidence.
- `r3_geometry/` preserves the isolated placement-only translation research that preceded product promotion, with explicit geometry-detector replay, placement/shape fact reconstruction, noise and unsupported controls, two clean rebuilds, and a fixed tamper matrix.
- `r3_complete/` freezes the synthetic workbench, direct IFC-chain reconstruction, positive/negative controls, repeatability, traceability, tamper rejection, and minimum three-file acceptance bundle used to gate the bounded v0.9.0 R3 product contract.
- `r3_complete/` extends the isolated R3 programme with rectangular-extrusion parameter dimensions, one topology-preserving tessellated vertex-deformation subtype, and direct containment/aggregation/type/material relationship changes. Its primary detector is direct IFC-chain comparison because the retained IfcDiff 0.8.5 channel has controlled blind spots. Passing this gate does not by itself change the public release boundary.

Local project models, absolute paths, credentials, and temporary external-sample results are not repository inputs. The deterministic Change Records remain the source of truth. The code makes zero model/API calls.

`r4_spatial_context/` preserves the generated synthetic local-view proof, row-to-GlobalId mapping and tamper checks. Its earlier candidate acceptance records are historical, not a 1.0.0 public-distribution approval. The separate public product illustration is generated by `scripts/generate_public_demo.py`; no private building excerpt is published.

`r4_spatial_context/` 保留合成局部查看验证、记录到 GlobalId 映射及篡改检查；早期候选验收记录为历史证据，不是 1.0.0 公开分发批准。独立公开产品演示由生成脚本从零构造，不公开私人建筑片段。

Research results are bounded technical evidence. They do not establish general IFC compatibility, professional engineering validation, or population-level user benefit.
